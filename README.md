**2025/11/18：**硬件记录：第一版因自动布线，导致线路问题，屏幕严重花屏。第二版和第三版应该是一样的问题，起初都是屏幕轻微闪烁，西工大logo背景泛绿色，目前发现是开发板的问题，换开发版后问题消失，但是新的问题就是上电后屏幕有时候只有背光，不会显示，然而上电一段时间后复位，就可以正常显示，考虑是上电时电源不稳定导致的问题，但是目前通过加延时还是没有得到有效据解决。

**2025/11/19：**硬件记录：看到一篇博客记录，通过示波器发现mipi发送指令的时候，跟reset信号是重叠的，所以要延迟一下mipi信号，通过设置init-delay-ms这个参数，而原来的设备树代码里是没有这个参数的，加上之后，发现竟然正常了，但测试在长时间断电后再上电，依然有黑屏的现象，但显示都正常，而且黑屏概率很低了，说明加这个参数是有用的，可以考虑给延时更大一些。

前面说换开发板后背景泛绿和闪屏消失，但是上电大概率黑屏，这个感觉是因为焊接问题，重新焊接之后又开始泛绿和闪屏了，但这个就不会黑屏。3v3的电容滤波甚至一个不给都不会有影响，背光驱动电流给20ma没问题(10欧电阻)，VCC给3v3，IOVCC给1v8，以上情况下，在加上init-delay-ms后基本都不会有问题，但长时间断电后再上电，依然有黑屏的现象，但可以确定不加init-delay-ms就会导致泛绿和闪屏的现象。

将rockchip,lane-rate注释掉后，系统会自动计算速率，上电黑屏的现象减少很多，同时观察到enable-gpio不存在，因此enable-delay-ms设置为0，目前看来，依然有概率会上电黑屏，但是重新上电后就会好。

黑屏问题，是因为背光没有点亮，测试发现gp7101没有输出pwm波，驱动在更新背光时，i2c返回无法检测到设备的错误信息，因此猜测是gp7101没有成功上电时，就进行了更新背光，所以导致背光无法点亮。软件解决，在更新背光的函数里加入while循环，判断只要i2c写的返回值为负值，就重新发送。后续可以用引出引脚上的pwm引脚直接作为背光引脚，就不用使用gp7101了。

**2025/12/6：**完善录像播放界面和录像界面的退出逻辑。修复播放视频有绿边的问题，原因是rga操作的源图像的长宽必须16位字节对齐，也就是长宽必须整除16，否则就会出现绿边。

rkaiq移植：需要在在 RkAiqCalibDbTypes.h 中添加 #define ISP_HW_V21。目的是为了调节曝光。rkaiq目前是以rkaiq_3A_server这么一个程序，开机后自动运行的，他就是对图像进行isp级别的处理，通过读取/etc/iqfiles下的isp配置文件进行处理，还包括了3A算法，比如AE(自动曝光)、AF（自动对焦）。文档中提供的方法是应用程序可以与isp_client通信从而联系到rkaiq_3A_server进行参数修改，但是这一方案没有任何资料参考。另一种方法是直接在应用程序里集成librkaiq.so，相当于自己去做rkaiq_3A_server的内容，这一部分有参考，但很复杂。

**2025/12/13：**硬件记录：原屏幕应该是烧坏了，可能是短路导致。换新的屏幕又出现了之前类似的问题，大体思路就是先看背光有没有问题，背光是没问题的。然后就是上电后屏幕显示问题，一直闪烁，或者色彩不对，硬件层面，滤波电容需要加上，换一个1.8v降压模块；如果硬件没问题，并且可以显示，那一般就是上电时序的问题，这次是将init-delay-ms加到了50ms，问题解决。
本来一上电，屏幕剧烈闪烁，还有噪点，但是能看到西北工业大学几个字一直在闪，色域正确。随后换了一个降压模块，好像还是闪，然后把滤波电容重新加上，不闪了，但是屏幕色域变了，随后将init-delay-ms加到50秒，显示正常。
