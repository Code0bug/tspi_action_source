# rk3566-ai-camera-display

#### 介绍
ai-cam-ui-widge 只是一个demo，简单测试屏幕和cam，还有检测功能。

cam-ui-widget 为相机项目

rockit 官方sdk，用来做编解码相关测试的

cam-dec-test 用来做视频解码测试

cam-ui-widget_1 尝试开发解耦框架，尚未成功

#### 开发记录

**2025/9/15：**成功添加ov8858驱动，并改成了4-lanes，注意4-lanes为full mode，只能用dphy0；采用双通道的方式，一个通道低像素作为界面显示，一个通道满像素作为拍照保存；预计将双通道改为双线程，即捕获给界面一个线程，拍照一个线程，这样界面就不会卡。

**2025/9/16：**成功添加dw9714自动聚焦马达，可以实现自动聚焦。

**2025/9/18：**成功使用rga进行像素转换加速，添加按键驱动，直接使用内核的按键驱动即可，添加后可以dmesg查找input，判断是哪一个event

**2025/9/19：**使用按键实现拍照、录像，添加界面切换按钮，实现三个界面切换

**2025/9/20：**设计图片和视频显示界面

**2025/9/21：**相册界面每次进入都要更新，已经完成。目前还需要解决摄像头发热问题，在相册与视频界面，应当关掉摄像头，不应该发热，但尚未实现。目前相册界面显示、更新图片都已完成。视频界面的视频播放尚未完成，需要添加rockit硬件解码。

**2025/9/22：**发热问题尚未解决。完善了录像保存机制，可以保存多个录像文件，并和相册一样实现更新。尝试实现视频解码，尚未成功。
