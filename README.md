# tspi-action

### 介绍

------

基于 RK3566 的运动相机Demo，支持实时预览、H.264/AAC MP4 录像、MP4 播放、硬件编解码。

**主要功能**

- 实时摄像头预览（VI 采集 + RGA 格式转换）
- H.264 硬件编码录像（VENC），AAC 音频编码，MP4 封装
- MP4 视频播放（VDEC 硬件解码 + AO 音频输出）
- 拍照（PNG/BMP）
- IMU 数据同步录制（ICM42688P，SPI + 中断异步通知）

**硬件平台**
- SoC：Rockchip RK3566
- 摄像头：OV8858（4-lane MIPI，自动对焦 DW9714）
- 屏幕：2.3 寸 MIPI LCD（带触摸）
- IMU：ICM42688P（SPI 接口）

分析一下为什么icm42688p中断引脚要配置成推挽输出而不是开漏输出。中断产生的流程是，int引脚默认高电平状态，当数据就绪时，将引脚拉低，产生下降沿信号，因此触发中断。开漏输出可以输出高电平，也可以输出低电平，满足要求。而开漏输出只能输出低电平，那么想要触发中断信号，就必须在外部接入一个上拉电阻，那么就是正常状态引脚被拉高，有数据时引脚输出低电平，产生下降沿信号。所以问题就是，我们没有这个外部的上拉电阻，而rk3566引脚的内部pull up貌似也不好用，所以引脚接收到的就一直时低电平信号，自然不会产生中断。
